## ARCHITECTURE에서 벗어난 판단 4건 (모두 문서 반영됨)

1. **프로젝트 10개** — `ProjectPathNormalizer`가 `Path.GetFullPath`를 쓰므로 Core 순수성 규칙 아래 두 Provider가 공유할 수 없어 `Daiso.Providers.Common`을 추가
2. **`IUsageReader` / `IProjectFactsReader` 추가** — `IProvider`만으로는 Claude의 날짜별 사용량 합산과 REQ 5.3 부가 정보를 얻을 수 없어 별개 인터페이스로 분리 (기존 시그니처는 그대로)
3. **Codex `response_item.message` role=user → System** — 실제 세션에서 AGENTS 지시문·플러그인 목록이 이 경로로 주입되는 것을 확인. ARCH의 "시스템 주입 제외" 원칙에 맞춤
4. **`IInstructionMarkerWriter.Strip` 추가 + `IInstructionMigrator`/`IInstructionMigrationService` 신설** — 마이그레이션은 마커 블록을 뺀 본문만 비교·복사해야 해서 블록 제거가 필요했다. import 전개는 파일을 읽어야 하므로 Core(순수)와 Infrastructure(IO)로 나눴다 (ARCHITECTURE §3.1·§3.3·§5.6에 반영)

## 유료 배포 판단 (2026-09-08)

기능·안정성·화면 일관성은 값을 받을 수 있는 수준이라고 본다. 근거와 남은 항목은 아래와 같다.

**근거**

- 시나리오 10개를 앱을 띄워 직접 몰아 확인했다 (`docs/UX_SCENARIOS.md` 1~7차). 잘림·짜부라짐·빈 판은 남아 있지 않다
- 창 최소 크기 1024×700을 강제해 레이아웃이 깨질 구간을 없앴다. 1024·1400·1600에서 확인
- 첫 실행(인덱스 없음)을 임시 인덱스 경로로 재현해 확인했다. 인덱싱 진행이 보이고, 끝나면 목록이 자동으로 갱신된다
- 배경 인덱싱과 화면이 같은 SQLite 연결을 쓰던 충돌(`IndexOutOfRange`)을 읽기·쓰기 연결 분리로 없앴다
- 화면 문구 277개가 리소스 한 파일에 있고 존댓말로 통일돼 있다. 키 누락·죽은 키 0
- 라이트·다크·시스템 세 테마에서 제목줄까지 같은 테마로 보인다
- 빌드 경고 0 / 오류 0, 테스트 251건 + Slow 2건 통과

**유료로 팔기 전에 남은 것 (기능 밖의 제품화 항목)**

| 항목 | 왜 필요한가 | 지금 상태 |
|---|---|---|
| 코드 서명 인증서 | 서명이 없으면 받는 사람이 SmartScreen 경고를 본다. 유료 제품에서 가장 먼저 신뢰를 깎는 부분 | 없음. 인증서 구매·발급은 사람이 해야 한다 |
| 업데이트 경로 | 고친 것을 사용자에게 전달할 방법. 최소한 "새 버전 확인" 링크나 릴리스 안내 | 없음 |
| 앱 안의 라이선스·개인정보 안내 | 세션 본문을 로컬 인덱스에 담는다는 사실을 앱에서 알려야 한다 | **끝. 설정 > 정보** 카드에 판 번호·개인정보 문단·이 앱이 쓰는 경로 3곳·상표 고지가 있다 |

**남은 두 항목은 코드로 끝낼 수 없다.** 사람이 해야 하는 일이라 절차만 적어 둔다.

| 항목 | 사람이 해야 하는 일 |
|---|---|
| 코드 서명 | OV/EV 코드 서명 인증서를 사서(연 단위) `signtool sign /fd SHA256 /tr <타임스탬프 서버> /td SHA256 d-AI-so.exe`. EV가 아니면 SmartScreen 평판이 쌓일 때까지 경고가 남는다 |
| 업데이트 경로 | 공개 저장소에 릴리스를 올리고 그 주소를 알린다. 이 앱은 인터넷에 나가지 않는 것을 약속으로 삼았으므로(설정 > 정보) **앱이 스스로 업데이트를 확인하게 만들지 않았다.** 자동 확인을 넣으려면 그 약속과 정보 카드 문구부터 바꿔야 한다 |

판 번호는 `src/Daiso.App/Daiso.App.csproj`의 `<Version>`이 정본이고, 설정 > 정보에 그대로 보인다. 릴리스마다 여기를 올린다.

## 작업 방식 (지켜야 할 것)

- **지시받은 것만 한다.** 다음 단계로 넘어가기 전에 묻는다
- **앱을 띄우거나 UI를 자동 조작하지 않는다.** 화면 확인은 사용자가 직접 한다.
  코드·빌드·`dotnet test`·CLI까지가 내 범위다
- 사용자 폴더(`%LOCALAPPDATA%\d-AI-so\`)를 쓰거나 지우기 전에 묻는다
- 실제 세션 파일은 읽기 전용. 삭제 검증이 필요하면 더미 폴더를 세션 루트로 지정한다
