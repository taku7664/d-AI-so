# UX 시나리오와 자가 검증

앱을 실제로 띄워 화면을 캡처하고, 아래 시나리오를 따라가며 걸리는 곳을 적었다.
검증 기준은 "처음 쓰는 사람이 멈추지 않고 목적을 끝내는가"와 "화면이 정보를 위계 있게 보여주는가"다.

측정 환경: Windows 10 Home, 1600×900 창, 세션 249건 / 1.28 GB, 테마 시스템(라이트).

## 시나리오

| # | 사람 | 하려는 일 | 성공 기준 |
|---|---|---|---|
| S1 | 처음 켠 사람 | 두 도구가 로그인되어 있는지, 언제 다시 로그인해야 하는지 안다 | 3초 안에 상태·남은 기간을 읽는다. 토큰 값은 어디에도 안 보인다 |
| S2 | 작업 시작 | 프로젝트 폴더에서 Claude를 새 창으로 연다 | 폴더를 고르고 실행까지 클릭 3회 이하. 실행될 명령을 미리 본다 |
| S3 | 어제 대화 이어가기 | 프로젝트를 찾아 세션을 고르고 이어서 연다 | 목록에서 원하는 세션을 눈으로 찾는다. 제목 줄이 읽힌다 |
| S4 | 기억 안 나는 대화 찾기 | "PROJECT_RULES"로 본문 검색해 해당 세션을 연다 | 검색어를 넣고 결과까지 클릭 1회. 결과가 프로젝트별로 묶인다 |

| S6 | 비용 확인 | 최근 7일 토큰 사용량과 추정 비용을 본다 | 숫자를 읽을 수 있다. 단가가 없으면 어디서 넣는지 안다 |
| S7 | 컨텍스트 점검 | 이 폴더가 AI에게 넘기는 파일과 중복·충돌을 본다 | 파일 목록이 로드 순서대로, 총량과 함께 보인다 |
| S8 | 규칙 만들기 | 조건 트리로 규칙을 만들어 프로젝트에 연동한다 | 트리 편집 버튼을 헤매지 않는다. 미리보기가 결과를 보여준다 |
| S9 | 지시문 정리 | CLAUDE.md와 AGENTS.md를 한쪽으로 맞춘다 | 좌우 차이를 보고 방향을 고른다. 고르기 전에는 아무 파일도 안 바뀐다 |
| S10 | 설정 | 인덱스 위치를 옮기고 단가표를 넣는다 | 입력란과 저장 버튼이 한 화면에 보인다 |

## 1차 검증에서 나온 문제 (수정 전)

### 심각 (기능이 막히거나 정보가 잘림)

| 위치 | 문제 | 근거 |
|---|---|---|
| Settings | 단가표 카드가 창 오른쪽으로 넘쳐 "모델 추가" 버튼이 잘린다. 저장·다시 읽기 버튼도 화면 밖 | 캡처에서 카드 오른쪽 경계와 버튼이 창 밖으로 나감 |
| 사용량 · 프로젝트별 | 토큰 수가 오른쪽에서 잘려 `1,545,8` 처럼 보인다 | 같은 캡처 |
| Terminal · 프리셋 | 버튼 글자가 `--permissic`, `--sandb` 로 잘린다 | 고정 폭 버튼 |
| Sessions · 목록 | 첫 프롬프트가 `<command-name>/goal</command-name>` 같은 원문 그대로 3줄까지 늘어나 행 높이가 들쭉날쭉 | 슬래시 명령으로 시작한 세션 |
| Sessions · 프로젝트 트리 | 전체 경로가 4~5줄로 줄바꿈되어 목록이 경로로 뒤덮인다 | 긴 경로 프로젝트 |

## 고친 것

### 공통 (ARCHITECTURE §6.2로 규칙화)

- 본문은 왼쪽 정렬 + 최대 폭 1280. 넓은 창에서 가운데로 떠 좌우가 비던 문제를 없앴다
  (`HorizontalAlignment=Left` + `MaxWidth`는 폭이 내용에 맞춰 줄어들므로, 열에 `MaxWidth`를 주고 내용은 Stretch로 채운다)
- 페이지마다 `제목 → 부제 → 행동 → 카드` 순서로 통일. 카드·글자 스타일을 6개로 제한
- 목록의 한 줄은 한 줄로 끝낸다 (`TextWrapping=NoWrap` + 말줄임). 전체 값은 ToolTip
- 큰 수는 `Formats.Tokens`로 줄여 쓰고(729,015,129 → 729.0M) 정확한 값은 ToolTip
- 파괴적인 버튼은 대상이 없으면 비활성. 빈 상태는 흰 판 대신 다음에 할 일을 적는다
- 왼쪽 이동 메뉴도 한국어로 (요약·터미널·세션·규칙·설정)

### 페이지별

| 위치 | 고친 내용 |
|---|---|
| Settings | 카드가 창 밖으로 넘쳐 잘리던 것을 고쳤다. 단가표는 카드 안에서 가로 스크롤하고, 저장·되돌리기는 아래 고정 바에 둔다. 단가가 없으면 안내를 띄운다 |
| 사용량 | 잘리던 숫자를 고정 폭·오른쪽 정렬로 바꿨다. 프로젝트는 이름을 크게, 전체 경로는 옅게. 단가가 없으면 InfoBar에서 설정으로 바로 보낸다 |
| Terminal | 프리셋 버튼 글자 잘림을 없앴다(고정 폭 → 넉넉한 격자). 누르기 전에 실행될 명령을 보여준다. 최근 폴더가 없으면 안내 |
| Sessions | 목록 제목에서 `<command-name>` 같은 태그를 걷어내 한 줄로 만든다. 프로젝트 트리는 이름 + 건수·용량만, 경로는 ToolTip. 이름이 겹치면 상위 폴더를 붙여 구분한다 |
| Sessions | 도구 표시를 이모지에서 색 원 + 머리글자로. 배지는 알약으로. 세션 id는 목록에서 빼고 ToolTip으로 |
| Sessions | 필터를 바꾸면 바로 적용된다("필터 적용" 버튼 제거). 선택 0건이면 삭제 버튼이 비활성이고, 선택 개수를 알약으로 보여준다 |
| Sessions | 아무것도 고르지 않았을 때 오른쪽 빈 흰 판 대신 안내를 띄운다. 컨텍스트 파일 목록은 표(있음 표시 · 경로 · 글자 수)로 |
| RuleMaker | 상단 버튼 9개를 5개 + 넘침 메뉴로. 조건 트리 버튼 8개는 `추가 ▾` · `감싸기 ▾` · 이동·삭제 아이콘으로 묶었다 |
| RuleMaker | 빈 규칙 미리보기가 `###` 껍데기를 보여주던 것을 안내 문구로 바꿨다. 규칙 요약은 `(빈 조건) → 행동 1개`처럼 조건 없음을 밝힌다 |
| Dashboard | 만료를 `2026-10-03까지 · 25일 남음`으로. 로그인돼 있으면 로그인 버튼을 숨기고, 상태는 색 점 + 알약으로 |
| Dashboard | 세션 요약을 숫자 3개(세션·용량·토큰)로 크게. `세션 보기` 링크로 목록으로 보낸다 |
| 전체 | 아이콘 버튼에 `AutomationProperties.Name`과 ToolTip을 달았다. Ctrl+S·Ctrl+O(RuleMaker), Ctrl+F(검색란 포커스)·F5(Sessions) |

## 3차: 테마

`다크`를 골라도 화면이 바뀌지 않는다는 보고를 받고 원인을 두 개 찾았다.

1. 테마를 창 생성 시점에만 적용해서, 고르고 저장해도 다시 시작할 때까지 그대로였다
   → 고른 즉시 적용하고 즉시 저장한다
2. `MicaBackdrop`은 OS 테마를 따라가므로, 시스템이 라이트인데 앱만 다크로 두면 배경은 밝고 글자만 밝아진다
   → 명시적 테마에서는 Mica를 끄고 그 테마의 단색으로 칠한다
3. Windows 10은 제목줄 색 API(`AppWindowTitleBar` 색상)를 지원하지 않아 위쪽에 밝은 띠가 남았다
   → `ExtendsContentIntoTitleBar`로 제목줄을 앱이 직접 그린다 (아이콘 + 앱 이름, 드래그 영역 유지)

확인: 시스템 · 라이트 · 다크 세 값을 차례로 골라 캡처했다. 세 경우 모두 창 전체(제목줄 포함)가 같은 테마로 보이고,
다시 시작 없이 즉시 바뀐다. 설정 파일의 값도 고른 즉시 반영된다.

남은 것: 폴더 선택 대화상자 확정 클릭. 사람이 직접 볼 필요가 있다.
