# 화면 시안

새 앱 화면의 기준이 되는 시안을 둔다. Stage 3부터 화면을 만들 때 이 시안의 배치·색·글꼴·아이콘을 따른다.
D안의 수치와 목록은 예시다. 동작도 흉내만 낸다. 2026-10-07 부터 만드는 시안은 이 PC 의 실제 데이터로 그린다.

## 지금 기준: D안

[daiso-d.html](daiso-d.html)을 브라우저로 연다. 파일 하나에 아이콘까지 들어 있고, 글꼴만 Google Fonts에서 받는다.
같은 내용이 저장소 주인 계정의 비공개 아티팩트(https://claude.ai/artifact/W2z5nEn52G4CkAQc6SvYFw)에도 있다.

| 자리 | 무엇 |
|---|---|
| 위 줄 왼쪽 | 프로젝트 선택기. 고르면 모든 탭이 그 프로젝트 기준이 된다. `Ctrl+P` |
| 위 줄 오른쪽 | 종(모든 프로젝트의 터미널 방 상태), 계정(도구 셋의 로그인 상태), 톱니(설정) |
| 왼쪽 메뉴 | 요약 · 터미널 · 세션 · 지침 · 프롬프트 · 사용량. `Ctrl+1~6` |
| 요약 | **[summary.html](summary.html)이 D안 요약을 대신한다** (2026-10-07). 타일 넷, 최근 세션 5개, 워크트리 현황. 프로젝트를 고르면 그 프로젝트로 좁힌다. 손볼 것과 마지막으로 하던 것은 종 팝업 |
| 사용량 | 맨 위 구독 한도(계정 단위), 그 아래 토큰. $는 없다 |

왜 이렇게 정했는지는 [../DECISIONS.md](../DECISIONS.md) "정한 것"의 2026-10-06 줄들에 있다.

## 시안에서 정해 둔 화면 규칙

- 제목 줄에는 이름과 상태만 둔다. 설명은 툴팁으로 넣는다
- 저장·삭제 같은 확정 버튼은 늘 아래 같은 자리에 둔다
- 고른 것은 형광펜 노랑(`--hl`)으로 칠한다
- 지침의 우선순위는 화면에서 "꼭 · 되도록 · 가능하면"으로 보여 주고, 파일에는 `MUST`·`SHOULD`·`MAY`로 쓴다
- 터미널 방은 "겉은 말풍선, 속은 진짜 터미널"이다. 입력칸에 쓴 글은 그 방의 CLI 입력 줄로 가고, `/`를 치면 명령·스킬 목록이 뜬다. 화면 없이는 안 되는 명령(`/login` 등)은 터미널 보기로 넘긴다
- 세션 삭제는 "휴지통을 거치지 않고 바로 지우기" 체크박스 하나만 묻는다
